# Jadys Fit: Image Size and File Preparation Guide

Jadys Fit provides browser-based tools for preparing images to meet pixel dimension, aspect ratio, format, and file size requirements.

**Use the tools:** https://jadysfit.com

## Start with your image requirements

Cropping, resizing, and reducing file size solve different problems:

- **Crop** to change the composition or aspect ratio.
- **Resize** to change the pixel width and height.
- **Compress** to target a smaller file size in KB or MB.

Check the requirements of the form or website where you will submit the image. If it specifies all three, crop first, resize second, then check and reduce the file size.

## Useful tools

- [Check image dimensions, format, file size, and aspect ratio](https://jadysfit.com/en/image-size-checker)
- [Compress an image to 200 KB or less](https://jadysfit.com/en/compress-image-to-200kb)
- [Explore all image tools](https://jadysfit.com/en)

The image size checker reads information from your image without creating a new output file or using a processing trial.
